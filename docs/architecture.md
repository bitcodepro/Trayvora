# Architecture

The desktop uses .NET 10 and Avalonia 12.1.3. Its composition root owns the tray icon, desktop lifetime, and services provided through dependency injection. The Windows hotkey adapter owns a Win32 message queue and posts presses to Avalonia's UI dispatcher. The application contracts have no dependency on Avalonia or Win32. The desktop shortcut controller registers a candidate before releasing the previous registration, and retains the previous shortcut if persistence fails. Settings are written atomically to a versioned JSON file.

The speech layer uses NAudio WASAPI shared mode to capture 16 kHz mono PCM, with at most 30 seconds in a fixed-size buffer. The overlay serializes capture, model download and transcription. It renders measured peak levels and keeps the transcript editable. Whisper.net runs inference locally on the CPU. The speech layer verifies the exact model revision and SHA-256 before inference. Model downloading writes to a temporary sibling file and renames it only after verification.

The Codex adapter starts an owned App Server process for each explicit submission. It opens or resumes a thread in the dedicated profile, correlates deltas and terminal events by thread and turn ID, and requests interruption before closing a cancelled session. A missing terminal event is shown as unknown. The profile stores Codex history. Trayvora stores the resumed thread ID and a local SQLite index of explicit submissions, terminal statuses and responses. The history view loads details by ID. One process owns the history directory while it is open. On first use, the database migrates transactionally and recovers abandoned running entries as Unknown. Tool summaries are projected from events for the active thread and turn. The hidden window listens for Windows suspend and resume. Completion notifications use the Windows notification area.

Sessions (the Discussion view) deliver each wave of messages addressed to different agents concurrently and process replies as they finish. Each delivery owns a thread-safe ReplyStream: Codex deltas and Claude Code stream-json events (`--output-format stream-json --verbose --include-partial-messages`, subagent events ignored) append to it, and the view copies snapshots into live bubbles on a 90 ms UI timer. Finished agent text is rendered by MarkdownView (Markdig with raw HTML disabled; only http and https links open), which rebuilds only changed top-level blocks while a reply grows. Session files are still written as whole JSON snapshots on a background queue.
