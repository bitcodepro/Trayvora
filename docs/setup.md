# Portable Windows setup

Unpack the Windows x64 package into any folder you can write to, on any drive (for example C:\Users\you\Downloads\Trayvora). All settings, history, sessions, models and Trayvora's Codex profile are stored in that folder. Verify the archive SHA-256 against its accompanying file. Double-click Trayvora.exe. On first use open **Accounts** at the bottom of the main window sidebar and sign in to ChatGPT (Trayvora's own Codex profile) and Claude; the browser opens and no commands need to be typed. Trayvora.exe sets up its folders itself: settings, history, models, its private Codex profile (codex-data) and the temporary and app-data folders that Codex uses are kept inside the application folder. It finds codex.exe in VOICEAGENT_CODEX_EXE, PATH, the remembered path in settings\codex-exe.txt, the Codex app, then the VS Code extension. Variables already set in the environment (for example VOICEAGENT_SETTINGS_DIR from a development shell) take precedence. The portable directory must be writable.

Install or locate Codex CLI separately. Set VOICEAGENT_CODEX_EXE to the full path of codex.exe when it is absent from PATH. Sign in with ChatGPT in the Trayvora Codex profile as shown in the README. The bundled .NET runtime does not include Codex or the Whisper model. Builds prepared with -ModelFile include verified Whisper Base. Otherwise download the model through Trayvora with consent. The Windows CPU runtime for Whisper may require the Microsoft Visual C++ 2022 x64 redistributable.

Set VOICEAGENT_REVQORA_EXE to the full path of revqora.exe, start Revqora with MCP enabled and restart VoiceAgent. Choose Automatic or Revqora MCP in the overlay. Select Local workspace from the tray only for direct local operations. A denied or unavailable Revqora route does not run through Git as a fallback.

Quit Trayvora before moving or uninstalling it. Remove the unpacked application directory to uninstall. Model, history and Codex data use the configured locations. Keep or remove those directories separately according to the data you want to retain. **More → Start with Windows** in the tray menu enables or disables startup for the current Windows user. Turn it off before removing the application folder. It only manages the entry belonging to that folder; an entry left by the old PowerShell launcher for the same folder is upgraded to start Trayvora.exe directly.

With Local Whisper selected, open Speech recognition in Settings and edit Whisper hints. Add one term or phrase per line; the changes save when you leave the field. The updated list takes effect on the next recording.
